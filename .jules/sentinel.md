## 2026-06-20 - Prompt-Based XSS via Unescaped User Content in HTML Generative Agents

**Vulnerability:** The Claude AI skill (`context-status/SKILL.md`) instructs the LLM to generate an HTML-based status card utilizing user-provided context strings (such as project names, decisions, and filenames) without explicitly mandating HTML entity sanitization. If a user provides context containing unescaped HTML characters, rendering these directly in the generated HTML card could lead to a prompt-based Cross-Site Scripting (XSS) injection.
**Learning:** In purely prompt-driven architectures where an LLM is expected to render dynamic UI components (like HTML or SVGs) incorporating arbitrary context strings, standard software XSS defenses must be explicitly defined within the agent's prompt instructions. LLMs may natively pass through HTML characters directly into outputs unless instructed otherwise, acting as a pass-through mechanism for script injections.
**Prevention:** Always enforce strict formatting rules in the system prompt / skill definition to explicitly sanitize or escape HTML entities (`<`, `>`, `&`, `"`, `'`) when placing user context strings into rendered HTML or SVG outputs.
